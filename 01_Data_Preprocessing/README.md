# 01 - Data Preprocessing

This module covers the foundational data preprocessing techniques used before feeding data into any Machine Learning model. Each notebook focuses on a specific preprocessing concept, implemented with practical examples.

## 📂 Contents

| # | Notebook | Description |
|---|----------|-------------|
| 01 | [Imputation](./01_Imputation.ipynb) | Handling missing values using techniques like mean, median, mode, and advanced imputation strategies. |
| 02 | [Outlier Detection](./02_Outlier_Detection.ipynb) | Identifying and treating outliers using statistical methods (IQR, Z-score) and visualization techniques. |
| 03 | [Encoding](./03_Encoding.ipynb) | Converting categorical data into numerical form using Label Encoding, One-Hot Encoding, and other techniques. |
| 04 | [Scaling](./04_Scaling.ipynb) | Feature scaling using Standardization and Normalization to bring features onto a common scale. |
| 05 | [Imbalanced Data Handling](./05_Imbalanced_Data_Handling.ipynb) | Handling class imbalance using techniques like SMOTE, undersampling, and oversampling. |
| 06 | [Training-Testing Split](./06_Training_Testing_Split.ipynb) | Splitting the dataset into training and testing sets for unbiased model evaluation. |

## 🎯 Why Data Preprocessing?

Raw data is often messy — it may contain missing values, outliers, inconsistent formats, or imbalanced classes. Data preprocessing ensures that the data fed into a Machine Learning model is clean, consistent, and well-structured, which directly improves model accuracy and reliability.

## 🛠 Tech Stack

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib / Seaborn (for visualization)
- imbalanced-learn (for handling imbalanced data)
